# AI-Drafted Text Wireframes - Inventory System

**Primary persona:** พี่ซัน, อายุ 30 ปี, เจ้าของร้าน มีประสบการณ์ 10 ปี และใช้คอมพิวเตอร์เป็นหลัก
**Design focus:** ทำงานบน PC ได้ชัดเจนและไม่ซับซ้อน แสดงการแจ้งเตือนสินค้าใกล้หมด และสรุปยอดขายรายวัน/รายเดือนสำหรับจัดการภาษี

## 1. Login

```text
+------------------------------------------------------------------+
|                         [ชื่อร้าน / โลโก้]                        |
|                                                                  |
|                    เข้าสู่ระบบจัดการร้าน                         |
|                                                                  |
|  อีเมลหรือชื่อผู้ใช้                                             |
|  [__________________________________________________________]    |
|                                                                  |
|  รหัสผ่าน                                                        |
|  [__________________________________________________________]    |
|  [ ] แสดงรหัสผ่าน                         [ ลืมรหัสผ่าน? ]        |
|                                                                  |
|                         [ เข้าสู่ระบบ ]                           |
|                                                                  |
|  ข้อความผิดพลาด (ตัวอย่าง):                                      |
|  ตรวจสอบอีเมล/ชื่อผู้ใช้และรหัสผ่าน แล้วลองอีกครั้ง              |
+------------------------------------------------------------------+
```

**Usability และ accessibility**
- วางแบบฟอร์มไว้กลางหน้า มีหัวข้อชัดเจนเพื่อให้รู้ว่าเป็นหน้าสำหรับเข้าสู่ระบบ
- ใช้ label ที่มองเห็นได้เหนือช่องกรอก ไม่ใช้ placeholder แทน label
- ปุ่มเข้าสู่ระบบมีข้อความบอกการกระทำชัดเจน และสถานะผิดพลาดบอกวิธีแก้
- มีตัวเลือกแสดงรหัสผ่านเพื่อช่วยตรวจสอบการพิมพ์

## 2. Dashboard

```text
+--------------------------------------------------------------------------+
| [ชื่อร้าน / โลโก้]  Dashboard  สินค้า  รับเข้าสินค้า  รายงาน  [บัญชี]   |
+--------------------------------------------------------------------------+
| สวัสดี, พี่ซัน                                      [ + เพิ่มสินค้า ]   |
|                                                                          |
| สรุปยอดขาย                         ช่วงเวลา: [ วันนี้ v ] [ เดือนนี้ v ] |
| +----------------------+ +----------------------+ +------------------+ |
| | ยอดขายวันนี้         | | ยอดขายเดือนนี้       | | รายการขายวันนี้  | |
| | ฿ [ยอดรวม]           | | ฿ [ยอดรวม]           | | [จำนวนรายการ]    | |
| +----------------------+ +----------------------+ +------------------+ |
|                                                                          |
| แจ้งเตือนสต็อก                                                           |
| +--------------------------------------------------------------------+ |
| | สินค้า             คงเหลือ       จุดแจ้งเตือน       สถานะ          | |
| | [ชื่อสินค้า]       [จำนวน]       [จำนวนขั้นต่ำ]      ใกล้หมด       | |
| | [ชื่อสินค้า]       [จำนวน]       [จำนวนขั้นต่ำ]      สินค้าหมด     | |
| +--------------------------------------------------------------------+ |
| [ ดูสินค้าทั้งหมด ]                                                      |
|                                                                          |
| รายงานยอดขาย                                                             |
| [ รายวัน ] [ รายเดือน ]             [ ดาวน์โหลดรายงาน / สำหรับภาษี ]   |
| [ กราฟยอดขายตามวันที่หรือเดือน พร้อมวันที่/ยอดขายที่อ่านได้ชัดเจน ]     |
+--------------------------------------------------------------------------+
```

**Usability และ accessibility**
- เมนูหลักคงที่และใช้ชื่อที่สื่อถึงงาน ช่วยให้ไปยังสินค้า รับเข้า และรายงานได้ง่าย
- ปุ่ม “เพิ่มสินค้า” เป็นทางลัดสำหรับเริ่มงานที่ทำบ่อย
- แยกยอดขายวันนี้/เดือนนี้ และแจ้งเตือนสต็อกให้เห็นตั้งแต่หน้าแรก
- สถานะสต็อกแสดงเป็นข้อความ ไม่พึ่งสีเพียงอย่างเดียว และมีจำนวนคงเหลือกับจุดแจ้งเตือนให้เปรียบเทียบ
- ตัวเลือกช่วงเวลาและปุ่มรายวัน/รายเดือนช่วยดูข้อมูลสำหรับจัดการภาษี

## 3. Add Product

```text
+--------------------------------------------------------------------------+
| [ชื่อร้าน / โลโก้]  Dashboard  สินค้า  รับเข้าสินค้า  รายงาน  [บัญชี]   |
+--------------------------------------------------------------------------+
| เพิ่มสินค้าเข้าคลัง                                      [กลับไปสินค้า] |
| กรอกข้อมูลที่จำเป็น (*) แล้วกดบันทึก                         |
|                                                                          |
| ชื่อสินค้า *                         รหัสสินค้า *                        |
| [____________________________]       [____________________________]     |
|                                                                          |
| ชนิดสินค้า *                         หมวดหมู่                            |
| ( ) จับต้องได้  ( ) ไฟล์ดิจิทัล       [ เลือกหมวดหมู่              v ]   |
|                                                                          |
| จำนวน *                              ราคา *                              |
| [____________________________]       [____________________________]     |
|                                                                          |
| รูปสินค้า (ไม่บังคับ)                                                     |
| [ เลือกรูป ]  ยังไม่ได้เลือกไฟล์                                          |
|                                                                          |
| ข้อความ validation (ตัวอย่าง):                                           |
| กรอกจำนวนเป็นตัวเลขตั้งแต่ 0 ขึ้นไป                                      |
|                                                                          |
| [ ยกเลิก ]                                        [ บันทึกสินค้า ]       |
|                                                                          |
| ข้อความสำเร็จ (หลังบันทึก):                                              |
| บันทึก “[ชื่อสินค้า]” สำเร็จ — จำนวนคงเหลือ [จำนวน] ชิ้น                 |
+--------------------------------------------------------------------------+
```

**Usability และ accessibility**
- แสดง label ค้างไว้เหนือทุกช่อง และใช้ `*` ระบุข้อมูลที่ต้องกรอก
- จัดฟิลด์เป็นกลุ่มและเรียงตามงาน ช่วยให้ตรวจสอบชื่อ รหัส ชนิด จำนวน และราคาได้ง่าย
- ข้อความ validation แสดงใต้ฟิลด์ที่เกี่ยวข้องและอธิบายวิธีแก้
- ปุ่ม “บันทึกสินค้า” เป็นปุ่มหลัก ส่วน “ยกเลิก” เป็นปุ่มรองที่แยกจากกัน
- หลังบันทึก แสดงข้อความยืนยันและจำนวนคงเหลือที่อัปเดต เพื่อให้รู้ผลทันที
